# Research notes and development decisions

Reviewed 2026-10-04. This document distinguishes published methods, NeuroLab's implementation, and work still needed. Numerical behavior before and after 0.4.7 must be compared as different model revisions.

## Primary references

1. [Berg et al., Sexual dimorphism in the complete Drosophila male central nervous system connectome, Cell (2026)](https://doi.org/10.1016/j.cell.2026.08.015), with the [official MaleCNS project and data access](https://male-cns.janelia.org/). This is the primary source for the bundled `male-cns:v1.0` adult-male CNS topology and annotations. Cite it whenever describing the dataset; the local thresholded derivative and its filtering are separately documented in [`DATA_PROVENANCE.md`](../DATA_PROVENANCE.md).
2. [Shiu et al., A Drosophila computational brain model reveals sensorimotor processing, Nature (2024)](https://doi.org/10.1038/s41586-024-07763-9), with [the authors' code and reproduction instructions](https://github.com/philshiu/Drosophila_brain_model). The model provides a published LIF-method reference (rest/reset -52 mV, threshold -45 mV, membrane time constant 20 ms, synaptic decay 5 ms, refractory period 2.2 ms, and 1.8 ms synaptic delay; synaptic weight is explicitly described as a free parameter). It uses FlyWire connectome versions, not MaleCNS. These values are comparative references, not automatically valid MaleCNS parameters, and adopting them would not make NeuroLab a reproduction of the paper.
3. [NeuroMechFly v2, Nature Methods (2024)](https://www.nature.com/articles/s41592-024-02497-y), with [FlyGym implementation](https://github.com/NeLy-EPFL/flygym). This work couples a body and simulated senses to controllers. It motivates measuring the body and environment separately from neural output. Minecraft collision physics and brightness rays are substantially simpler than this embodied model.
4. [Forge GameTest documentation](https://docs.minecraftforge.net/en/1.21.x/misc/gametest/). Tests can exercise registered entities and world behavior in a real development server. NeuroLab uses the pinned Forge 52.1.16 implementation and its `forge:empty3x3x3` template; documentation for newer Forge revisions can differ.
5. The [Fly Brain Minecraft reference project](https://github.com/blendi-remade/fly-brain-minecraft) is a game-embodiment precedent. Refer to [our data notice](../DATA_PROVENANCE.md) for the bundled derivative's attribution and checksum. Sharing a dataset does not establish equivalent behavior or validation.
6. [Li et al., The connectome of the adult Drosophila mushroom body provides insights into function, eLife (2020)](https://doi.org/10.7554/eLife.62576) analyzes adult mushroom-body compartments, Kenyon-cell / mushroom-body-output-neuron pathways, and dopaminergic modulation. It supports a circuit-specific learning hypothesis; it does not justify applying one reward/pain update rule uniformly to every edge in the CNS.
7. [Aso et al., The neuronal architecture of the mushroom body provides a logic for associative learning, eLife (2014)](https://doi.org/10.7554/eLife.04577) maps adult mushroom-body compartments and the anatomically distinct dopaminergic inputs relevant to associative learning.

## Current evidence and limits

| Layer | What is implemented | What remains unvalidated |
| --- | --- | --- |
| Graph | Bundled MaleCNS v1.0 derivative, 176,422 neurons and 6,287,749 retained directed connections | Loss from filtering, uncertain annotations, complete physiological coverage |
| Dynamics | Sparse LIF updates; each active neuron visited once per 0.5 ms substep; explicit refractory countdown; only known signed transmitter labels drive signed current | Fitted time constants, transmitter/receptor effects, conduction delays, biological firing statistics |
| Input | Brightness rays and world proxies mapped to annotated sensory populations | A retinal image, optic flow, realistic odor plumes, receptor calibration |
| Readout | Named neuron-type groups decoded to game commands | Functional calibration of forward/turn/lift channels, including annotation and side coverage |
| Body | Minecraft movement and collision checks; server-observed position, displacement, and trajectory | Anatomical biomechanics; position deltas do not identify which controller caused motion |
| Learning | Pre-before-post pairing on real directed edges, bounded reward eligibility, per-edge inspection, and transferable imprints | Compartment-specific dopamine plasticity, fitted learning curves, or evidence that a task was learned |
| Measurements | Session IDs, neural/world ticks, sampled spike/synapse activity, trial labels, queue/drop status | Complete spike trains, all substeps, electrophysiology, causal attribution from a video |

The in-world head-level hologram reuses sparse samples of the bundled anatomical positions and directed edges, then highlights IDs reported as firing in the latest telemetry packet. It is useful for communicating live state, but it does not depict the full graph or all activity and should not be presented as a measured biological brain scan.

## Scientific fidelity guardrails

- Keep the MaleCNS v1.0 neuron identities and directed connectivity as the biological substrate. Do not add hand-authored edges, invented neuron labels, or game-specific “brain circuits” to make behavior look smarter. Any reduced/thresholded graph must state its exact filtering, indexing, and sign-assignment operations; see [`DATA_PROVENANCE.md`](../DATA_PROVENANCE.md).
- Keep three kinds of statements separate in code, telemetry, and writing: (1) measured connectome data, (2) computational assumptions (LIF dynamics, external stimulation, decoding), and (3) Minecraft embodiment. A game response is not by itself evidence that the fly would show that behavior.
- A neuron with unknown transmitter polarity remains in the structural graph and contributes to anatomical connection counts, but it must not be silently assigned excitatory current. The LIF transfer now applies signed current only where the bundled data assigns a nonzero polarity; unknown-polarity edges are excluded from current injection and reward-modulated edge updates. This is an explicit conservative simulation policy, not proof that those synapses are physiologically inactive.
- Treat published parameters as traceable hypotheses, not universal biological constants. In particular, Shiu et al.'s published LIF model is based on FlyWire data. Before using its parameters with MaleCNS, record the parameter-by-parameter comparison, preserve the current implementation as a named baseline, and run reproducible stability and circuit-response tests. Never describe that port as a reproduction without matching the paper's dataset and full method.
- Do not call the current reward/pain edge adjustment biological learning. It now requires a simulated pre-before-post spike pair on an existing directed edge within 10 ms of simulated neural time, then uses a bounded, decaying eligibility trace for game-derived reward or pain. That makes the update inspectable and timing-dependent, but it still lacks compartment-specific dopamine signaling, a fitted plasticity curve, and behavioral validation. Keep it labeled as an experimental game-level plasticity rule.
- Minecraft block/entity labels provide a separate, bounded associative navigation memory. Flower/water/fire/zombie/villager cues, player identity, encountered block types, and recent blocked cells can influence assisted steering. Repeated player damage accumulates an aversive cue for that player's UUID; environmental damage pairs a detected hazard block with pain; observed health recovery while standing on a non-hazard block adds a weaker positive association. The latter is correlation only and can be confounded by unrelated regeneration. These memories persist separately from the connectome and are not transferred by a synaptic imprint. Immediate looming/pain reflexes are distinct from learned associations, which strengthen gradually rather than after a hard-coded number of hits. These scores are not connectome measurements; identity/block learning is a Minecraft adapter proxy, not a claim about a reconstructed fly circuit. Flower targeting is gated by positive contact experience; Neuro Fly rain shelter and basic harm avoidance remain explicit automatic rules. Calling this visual object recognition or learned global path planning would overstate the implementation. The actual rendered Connectome lines show anatomical positions and selected learned weight deltas, not measured synaptic currents.
- Any future connectome-faithful learning profile must leave the bundled MaleCNS topology immutable, identify the eligible mushroom-body cell types/compartments and DAN signals from the data, and store learned state separately from baseline synapse counts. A global update to every recently active edge is not supported by the cited circuit literature. Until eligibility, timing, sign, and retention are tied to a documented mechanism and tested against published behavioral outcomes, keep learning exploratory and report it as such.
- The dashboard's visual-receptor-to-motor path is a shortest directed anatomical route through the bundled filtered graph. It is an existence/pathway view, not evidence that the displayed chain was active in the current sample; telemetry includes only a bounded sample of firing neuron IDs and does not include complete edge-resolved spike trains. Roster queries report currently attached mobs in the player's current dimension, not unloaded entities or other dimensions.

## Decisions in 0.4.7

- A sparse active set must survive capacity growth and contain a neuron only once per integration substep. The previous shared membership/buffer scheme did not enforce both conditions. Separate reusable sets now provide that guarantee, including through refractory periods.
- Replacing a learned imprint clears eligibility traces belonging to the previous imprint. Pending copies are transferred atomically to the worker.
- Ordinary mobs remain under vanilla AI in assisted mode. The decoder adds small bounded steering/velocity nudges instead of replacing their entire movement tick; the custom Neuro Fly retains its direct flight controller. This makes the attach adapter an influence layer, while `neural` is the isolated full-control condition.
- The Neuro Experiment Chair is a subject-docking fixture, not a stimulus or electrical-tissue model. Test inputs are delivered separately through the Neuro Monitor or stimulus probes; Minecraft has no electrode impedance, analog voltage/current, or intracellular recording here. Spikes, active cells, and synaptic events on the monitor are model outputs, not measured biological signals.
- The top-right HUD selects the viewed subject or nearest currently tracked brain. Hologram rendering requires live telemetry; its visibility depends on entity tracking range and has no server-side effect.
- Observations need a run ID and a neural tick. A server can sample the same neural snapshot repeatedly when the simulation falls behind. Offline analysis deduplicates consecutive repeated neural ticks when calculating neural means; it does not invent a full-run spike total.
- A world owns its log queue. Small logs flush at least once per second under normal I/O conditions; a full queue drops records instead of waiting on a game tick. Missing end markers and dropped records are visible in analysis. A flush is not an OS-level durability guarantee against power loss.

## Next research milestones

1. **Model and readout audit:** establish a frozen MaleCNS baseline; document every neuron/synapse parameter and its source or “exploratory” status; then count the exact annotated neurons selected by each decoder, verify hemisphere information, and test each population separately. Acceptance: a machine-readable population manifest, parameter manifest, and reproducible response matrix. A changing Minecraft trajectory alone is insufficient.
2. **Measured body feedback:** extend position records with contacts and action suppression while perched. Acceptance: distinguish requested motion from achieved motion and identify blocked or externally driven movement.
3. **Matched trials:** explicit random seeds, clean learning state, controlled initial world/entity conditions, and a reset procedure. Acceptance: repeated numeric inputs reproduce the same neural snapshots within a pinned model revision.
4. **Ablations:** compare observation, neural-only, and assisted modes; later add controlled population silencing. Acceptance: state which component changed and preserve all other conditions.
5. **Load study:** measure server tick duration, worker backlog, memory, and real-time factor for 1, 4, and 16 brains on the lab PC. Acceptance: publish hardware, configuration, raw logs, and failed runs alongside the summary.

These are planned experiments, not claimed results. The video can show a connectome-informed controller driving a game entity; the technical report should show the same run's conditions and limitations.
